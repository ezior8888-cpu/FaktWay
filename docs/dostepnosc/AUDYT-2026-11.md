## 3. Kontrast tokenów motywu (`app/globals.css`)

### Wzór

Zgodnie z WCAG 2.1 (1.4.3, 1.4.11):

```
kanał sRGB c w [0,1]:  c_lin = c/12.92                    dla c <= 0.04045
                       c_lin = ((c+0.055)/1.055)^2.4      w przeciwnym razie
L = 0.2126*R_lin + 0.7152*G_lin + 0.0722*B_lin
kontrast = (L_jasniejszy + 0.05) / (L_ciemniejszy + 0.05)
```

Tokeny motywu są w OKLCH, więc najpierw OKLCH -> OKLab -> liniowy sRGB
(macierz Ottossona), obcięcie do [0,1], potem wzór wyżej. Tło półprzezroczyste
(`/10`, `/20`) mieszane z kartą w przestrzeni sRGB. Te same funkcje ma
`tests/unit/helpers/kontrast.ts`; dla par, które motyw już testuje
(`--primary` 5,10:1, `--destructive` na `/10` 4,95:1, ciemny `--primary-foreground`
7,02:1) wynik tego audytu zgadza się z liczbami w komentarzach, co potwierdza
poprawność liczenia. Progi: 4,5:1 tekst, 3:1 duży tekst (>= 24 px albo
>= 18,66 px pogrubiony) i elementy interfejsu.

## 6. Czego ten audyt nie sprawdził

- Faktycznego renderu (kolor przezroczystych tłem, `backdrop-blur`,
  `glass-white`): kontrast liczony z tokenów i klas, nie z pikseli. Strony
  marketingowe z animacją wejścia (`components/site/motion.tsx`) mają znane
  fałszywe wyniki axe w trakcie animacji (patrz komentarz w
  `06-accessibility.spec.ts:44-49`).
- Kontrastu toastów sonner z `richColors` (kolory dostarcza CSS biblioteki,
  nie nasz kod) i widżetu Turnstile (kolory w iframie; ekrany logowania
  ustawiają `theme='light'` na stałe, `login/page.tsx:147`).
- Zachowania z czytnikiem ekranu (VoiceOver, NVDA): kolejność czytania, czy
  `role="alert"` rzeczywiście zostaje ogłoszony.
- Okien opartych na Base UI (`Dialog`, `Sheet`, `Select`, `Popover`): pułapka
  fokusu, zwrot fokusu i Escape są w bibliotece, tu sprawdzone tylko
  statycznie (etykiety „Zamknij” są). Własne okna: tylko panel pomocy (A-10)
  i baner zgody, który nie jest modalny.
- Aplikacji mobilnej Expo (`mobile/`) i PDF faktur (WCAG 2.1 dla PDF to inny
  zestaw kryteriów).
- Zachowania fokusu po nawigacji między trasami (`ShellScrollMemory`,
  `DashboardRouteFlags`): wymaga uruchomienia.
- Wykrywanie `<th scope>`, podpisów tabel (`<caption>`) i kolejności
  nagłówków na każdej stronie panelu: sprawdzono nagłówki `<h1>` (45 plików
  z `<h1>`, `expenses/page.tsx:64` ma `sr-only`), nie przeszukano wszystkich
  podstron ustawień.
